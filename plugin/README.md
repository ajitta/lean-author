# Lean Author

Lean Author helps you write Claude agents, skills and commands that follow a consistent structure: a Markdown heading skeleton with XML tags for examples, constraints and boundaries, a short SKILL.md body, and reference files loaded only when needed. It aims at instructions that keep the core directives and drop the sprawl.

Status: pre-release (0.1.x). The skill is a placeholder until 1.0.0.

Works in Claude (claude.ai, desktop, Claude Code) as a plugin and in Codex as a plain skill folder. Install in Claude Code 2.1.275 or later:

```
/plugin install lean-author --marketplace ajitta/lean-author
```

Other install routes: https://github.com/ajitta/lean-author
